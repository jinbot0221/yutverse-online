# Yutverse Online

React + TypeScript + Vite, Three.js/React Three Fiber, Express + Socket.IO, SQLite 기반 증강 윷놀이입니다. PC·모바일 세로/가로 화면과 싱글/온라인 2~4인 개인전을 지원합니다.

로그인 후 첫 화면에서 **싱글플레이 / 멀티플레이**를 고릅니다. 싱글은 사람 1명과 AI 1~3명, 멀티는 실제 사용자 2~4명으로 진행합니다. 멀티플레이를 누르면 참가 중인 온라인 방도 복원합니다. 싱글은 말 선택 화면에서, 멀티는 방 생성 시 **일반 / 증강 모드**를 고릅니다. 방 목록과 대기실·인게임에 방식이 표시됩니다. 시작한 경기의 방식은 중간에 바꾸지 않으며 저장·재접속 후에도 유지합니다.

## 실행

Node.js 24 이상, npm을 사용합니다. `.nvmrc`는 24이며 서버는 Node의 `node:sqlite`를 사용합니다.

```sh
npm ci
npm run dev:server  # 터미널 1: API/Socket.IO, 3001
npm run dev         # 터미널 2: 웹 5173, API/소켓을 3001로 프록시
```

싱글은 로그인 없이 실행 가능하며 규칙과 AI는 브라우저에서 동작합니다. 서버 없이 싱글만 개발할 때는 `npm run dev`를 사용합니다. 오프라인 새로 접속을 위한 서비스 워커/PWA는 없습니다.

```sh
npm test
npm run build
npm start           # 3001에서 정적 웹·API·소켓을 함께 제공
```

Mac 임시 공개 주소는 [MAC_SETUP.md](MAC_SETUP.md), [DEPLOYMENT.md](DEPLOYMENT.md)를 참고합니다. 서버를 운영하는 Mac에서 다음과 같이 실행합니다.

```sh
caffeinate -i npm run deploy:quick
```

`PUBLIC GAME URL`을 공유합니다. 서버·터널 프로세스와 Mac이 계속 실행 중이어야 합니다. 현재 변경은 공통 서버 규칙과 순위 저장 방식도 변경하므로 업데이트·빌드 후 서버/터널을 재시작해야 합니다. Node 24가 구형 macOS에서 공식 지원되는지는 별도이며, 사용자가 제공한 Mac 실기 실행 로그와 클라우드 검증을 구분합니다.

## 현재 게임 화면과 규칙

- 말은 **수달·다람쥐·고양이·강아지 얼굴** 중 선택합니다. 얼굴만 있는 입체 모델이며 말 4개에 같은 동물을 적용합니다. 색상과 번호로 소유자·말을 구분합니다. 이동·업기·잡혀 돌아가기·완주 연출과 카메라 확대/회전/초기화, 저사양 모드를 제공합니다.
- 도·개·걸·윷·모·빽도, 잡기, 업기, 지름길, 추가 던지기와 결과 보관/사용 순서 선택을 지원합니다. 갈림길에서 이동을 시작할 때 직접 경로를 고릅니다. 첫 완주 뒤에도 나머지 순위까지 결정합니다. 세부 기준은 [RULES.md](RULES.md)에 있습니다.
- 네 윷을 각각 앞/뒤 50%로 계산합니다. 모 1/16, 빽도 1/16, 도 3/16, 개 6/16, 걸 4/16, 윷 1/16입니다. AI 난이도는 확률을 바꾸지 않습니다.
- 결과는 윷 던지기 모션이 끝난 뒤 화면 가운데 팝업으로 표시합니다. 윷·모는 빛나는 강조 효과와 추가 던지기 안내를 표시합니다. 동작 줄이기 설정에서는 튀는 모션을 줄입니다.

### 일반 모드: 세 가지 증강

| 증강 | 방식 | 효과 |
| --- | --- | --- |
| 잡기 1회 까방권 | 자동 | 상대의 잡기 1회를 막습니다. 업힌 무리는 함께 보호합니다. |
| 1칸 더 가기 | 수동 | 이동 전 사용하면 앞으로 1칸을 더 갑니다. 빽도에는 사용할 수 없습니다. |
| 빽도 까방권 | 자동 | 빽도 1회를 무효로 하고 공정한 확률로 다시 던집니다. 보관 중인 다른 결과는 유지합니다. |

두 모드 모두 **1·6·12라운드 시작**에 생존자 전원이 순서대로 하나씩 선택합니다. 라운드는 플레이어들의 기본 차례가 한 바퀴 돌아야 증가하며, 추가 던지기로는 증가하지 않습니다. 일반 모드는 각 종류를 한 번만 획득합니다. 사용한 카드는 소모 상태로 남으며 충전되지 않습니다. 후보는 미보유 종류만 표시하므로 보통 3개 → 2개 → 1개입니다.

선택마다 **후보 다시 뽑기 1회**를 사용할 수 있고 원래 60초 제한은 연장되지 않습니다. 일반은 남은 종류를 전부 보여주므로 리롤해도 종류가 같습니다. 선택 중 전체 규칙은 정지하며 선택 당사자만 선택 화면을 보고 다른 사람은 윷판을 유지합니다. 시간 초과 시 첫 후보를 자동 선택합니다.

### 증강 모드: 사용자 제공 92종

범용 **57종**은 1·6·12라운드, 시작 전용 **14종**은 1라운드, 후반 전용 **21종**은 6·12라운드에 등장합니다. 기존 27종 후보 풀을 사용자 제공 목록으로 교체했습니다. 중복 획득·충전은 없으며 역전 찬스는 별도로 증강 4개를 지급합니다. 기본 이동 보너스는 최대 +2칸, 라스트 댄스의 배율은 그 뒤에 적용합니다.

시작 화면, 말 선택 화면, 온라인 대기실의 **모든 증강 보기**에서 이름·효과 검색과 모드·등장 시점 필터를 사용할 수 있습니다. 경기 중 플레이어 이름을 누르면 보유 증강, 특수말, 보호막·폭탄·체력을 확인합니다. 후보 카드는 다른 사람에게 공개하지 않습니다.

대상·방향·투표가 필요한 증강은 추가 선택 창을 표시하고 전체 규칙을 멈춥니다. 칸 선택에는 작은 윷판 지도도 제공합니다. 서버는 선택 권한, 횟수, 60초 타임아웃을 검사합니다. 블러핑의 실제 결과와 안개 밖 상대 좌표는 다른 참가자에게 가려 전송합니다. 특수 승리자는 가장 앞선 미확정 순위를 받고 나머지는 계속 진행합니다. 공동 승패는 같은 순위·점수로 기록합니다. 죄수의 딜레마는 선택창에 협력/배신 조합별 추가 던지기 보상표를 표시합니다.

판 접기·회전, 격자 방식 알까기, 죄수의 딜레마 보상, 체력 4/피해 1 등 원문에 없던 디지털 판정 기준과 전체 목록은 **[CUSTOM_AUGMENTS.md](CUSTOM_AUGMENTS.md)**에 정리했습니다. 물리 시뮬레이션으로 원작을 재현했다고 주장하지 않습니다. 새 증강 조합의 밸런스와 모든 장기 상호작용을 완전히 검증한 상태는 아닙니다.

이전 계정·전적·진행 중 경기는 삭제하지 않습니다. 과거 캐릭터는 동물 표시로 연결하고 과거 27종 증강 효과는 저장 경기 호환용으로 해석합니다. 방식 정보가 없는 저장 경기는 일반 모드, 라운드 정보가 없는 경기는 1라운드부터 처리합니다. 새로 시작한 경기에 새 규칙을 적용하는 것을 권장합니다.

## 온라인 방과 저장

회원가입은 아이디(영문·숫자·밑줄 4~24자, 대소문자 구분 없음), 비밀번호(8~128자), 닉네임(1~16자)을 사용합니다. 비밀번호는 salt + scrypt, 세션·복구코드는 해시로만 저장합니다. 로그인 유지 선택 시 같은 주소에서 최대 30일, 해제 시 탭 저장소 및 서버 최대 12시간입니다. 임시 공개 주소가 바뀌면 같은 계정으로 다시 로그인해야 합니다.

신규 가입 시 복구코드를 한 번 제공합니다. 기존 계정은 로그인 후 `회원정보`에서 현재 비밀번호를 확인하고 코드를 발급합니다. 로그인 화면의 회원정보 찾기에서 코드로 아이디 조회·비밀번호 재설정을 합니다. 재설정은 모든 기존 세션과 이전 복구코드를 폐기합니다. 사전 코드가 없고 비밀번호도 모르는 기존 계정의 자동 복구, 이메일/SMS 인증, 외부 로그인은 미구현입니다.

멀티플레이는 방 목록 클릭으로 입장합니다. 제목·2~4인·선택 비밀번호를 설정할 수 있고 초대 코드 입장도 지원합니다. 비밀방 암호는 salt + scrypt로 저장하고 목록·공개 상태에는 전송하지 않습니다. 정원·비밀번호·준비 여부·방장 권한을 서버에서 검사합니다. 같은 세션의 온라인 동시 접속은 마지막 소켓 연결만 유지합니다.

서버만 윷 결과·이동·증강·순위를 확정합니다. 오래된 revision, 불법 이동, 타인 차례 행동을 거부합니다. 90초 재접속 유예, 120초 행동 시간 제한, 60초 증강 선택 시간을 적용합니다. 게임 나가기는 확인 후 기권 처리하며 이미 완주한 순위를 보존합니다. 온라인 기권 기록은 그 경기의 최종 종료 시 확정합니다.

점수는 2인전 20/0, 3인전 30/10/0, 4인전 40/20/5/0입니다. 누적·월별(UTC) 랭킹과 전적을 저장합니다. 로그인하고 시작한 싱글은 별도 서버 기록으로 저장하며 온라인 점수에는 반영하지 않습니다. 연결 실패 시 같은 계정의 로컬 대기 기록을 재전송합니다. 비로그인 싱글은 브라우저에만 저장합니다.

기본 DB는 `data/yutverse.sqlite`이며 `YUTVERSE_DATA_DIR`로 변경할 수 있습니다. `PORT` 기본 3001, 별도 웹 출처가 필요하면 `WEB_ORIGIN`을 지정합니다. 서버 프로세스는 1개만 실행합니다. 기존 DB를 삭제하지 않고 새 테이블을 추가합니다. 반복된 동일 증강 선택도 `augment_choice_events`에 선택 순서별로 저장합니다. SQLite 백업은 일관된 백업 방법으로 수행하고 운영 중 DB를 임의 삭제하지 않습니다.

## 증강 도감과 문제 제보

`/augments`는 로그인 없이 직접 열 수 있는 별도 증강 도감입니다. 92종과 일반 모드 기본 3종을 모드·등장 시점·이름·효과로 찾습니다. 기존 빠른 보기 팝업도 유지합니다.

`/report`는 게임 동작·화면 깨짐·기타 의견 제보 페이지입니다. 로그인 화면, 시작 화면, 말 선택 화면, 대기실과 경기 중 설정에 링크가 있으며 게임에서 열면 새 탭을 사용합니다. 이 페이지들은 게임 소켓을 연결하거나 게임 진행을 멈추지 않습니다. 원래 경기의 턴·선택 제한시간은 계속 흐릅니다.

제목·문제 설명은 필수이며 재현 방법·기대 동작·닉네임·연락처와 PNG/JPG/WebP 스크린샷(최대 1MB)은 선택입니다. 화면 크기·브라우저·모드·라운드·방 코드 진단 정보는 미리 보고 제외할 수 있습니다. 비밀번호·세션 토큰·전체 게임 상태·주소의 임의 쿼리 값은 자동 수집하지 않습니다. 기본 웹 양식은 로그인 없이 제출하며 별도 계정 정보를 붙이지 않습니다.

제보는 서버 SQLite의 `issue_reports`에 이미지와 함께 저장합니다. 성공한 저장에만 접수 번호를 표시하며 서버 연결 실패 시 화면의 작성 내용을 유지합니다. 공개 제보 조회 API 및 이메일/Slack 자동 알림은 제공하지 않습니다. 운영하는 Mac에서 다음 명령으로 확인합니다. 같은 `YUTVERSE_DATA_DIR`을 사용하세요.

```sh
npm run reports:list
npm run reports:show -- 접수번호
npm run reports:export -- 접수번호 ./report-export
```

목록은 최신 100건, 상세는 제보 본문과 진단 정보입니다. 내보내기는 JSON 및 첨부 이미지를 지정 폴더에 저장하며 기존 파일을 덮어쓰지 않습니다. 다른 사람의 제보를 브라우저에 공개하지 않습니다. 기존 DB는 삭제하지 않고 서버 재시작 시 테이블을 추가합니다.

## 검증

브라우저 검사는 Playwright와 `/usr/bin/chromium`을 사용하며 `CHROMIUM_PATH`, `YUTVERSE_URL`을 지정할 수 있습니다. 테스트용 계정·전적을 생성하므로 **테스트 전용 DB**를 사용합니다. 스크린샷은 `/tmp/yutverse-browser`에 저장합니다.

```sh
npm test
npm run build
npm run test:pages-browser        # 독립 도감·제보 첨부/실패 복구·게임 탭 유지
npm run test:fold-browser         # 가로/세로 접기 후 완주, 딜레마 보상표
npm run test:catalog-browser      # 92종 검색/시점 필터, 리롤 유지, 효과·대상 선택
npm run test:game-style           # 일반/증강 싱글·방 목록·재접속
npm run test:family-browser       # 시작 화면, 동물, 3증강, 이펙트, 다른 사람 선택 중 윷판 유지
npm run test:characters-browser   # 네 동물 선택·유지
npm run test:rooms-browser        # 방 목록·비밀방·온라인 플레이
npm run test:accounts-browser
npm run test:recovery-browser
npm run test:turn-augments
npm run test:animation
npm run test:rules-browser
npm run test:game-view
YUTVERSE_LAYOUT_PLAYERS=4 npm run test:online-layout
```

공통 엔진 테스트는 네 윷 16조합·경로·잡기·업기·레거시 증강·신규 세 카드·중복 거부/소모·1/6/12라운드·92종 획득/사용 경로·AI 완주를 검사합니다. 서버 테스트는 실제 소켓 2/3/4인 경기, 권한·개인 후보 보호, 비밀번호·계정 복구, SQLite 복원, 중복 저장 방지와 증강 선택 기록 및 공동 순위 점수을 확인합니다.

캐릭터 수집·상점, 고정 도메인 상시 운영, 다중 서버/Redis는 미구현입니다. Three.js 번들 크기 경고는 남아 있습니다.
