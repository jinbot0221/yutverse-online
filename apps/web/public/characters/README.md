# 캐릭터 이미지 시트

`heroes.png`는 대화에 첨부된 다섯 캐릭터 그림을 기반으로 이미지 생성 도구로 정리한 게임용 투명 PNG입니다. 1536×1024, 3열×2행의 동일 크기 셀을 사용합니다.

| 위치 | 캐릭터 ID |
| --- | --- |
| 1행 1열 | dwarf |
| 1행 2열 | archer |
| 1행 3열 | fighter |
| 2행 1열 | knight |
| 2행 2열 | mage |
| 2행 3열 | 비어 있음 |

UI는 CSS 배경 위치, Three.js는 텍스처 UV로 동일한 셀을 표시합니다. 캐릭터 이름은 게임 내 표시용 임시 이름이며 능력 차이는 없습니다. 전체 셀에는 투명 여백이 포함되고, 말의 발 위치에 맞춰 스프라이트 기준점을 조절합니다.
